# 題目一：Ackermann Function

## 解題說明

這題要用兩種方法來算 Ackermann Function，一種是遞迴，一種是非遞迴。主程式會一直讀入 m 和 n，然後印出 A(m,n) 的答案。

Ackermann Function 的規則有三種情況：

| 條件 | A(m,n) 的值 |
|------|-------------|
| m = 0 | n + 1 |
| m > 0 而且 n = 0 | A(m-1, 1) |
| m > 0 而且 n > 0 | A(m-1, A(m, n-1)) |

## 解題策略

### 遞迴版本

遞迴版本我是照著規則一條一條寫成 if。

#### 先判斷 m 是不是 0

先看 m 是不是 0。如果是，直接回傳 n + 1，不用再呼叫自己。

#### m 大於 0 並且 n 是 0

改算 a(m-1, 1)，m 減一。

#### m 和 n 都大於 0

要先算裡面的 a(m, n-1)，算出來的答案當成外面那一層的 n，再去算 a(m-1, 那個答案)。

#### 為什麼一定會停下來

每呼叫一次，m 和 n 都會往比較小的方向走，所以最後一定會碰到 m 等於 0 而停下來。

### 非遞迴版本

非遞迴版本的想法是，遞迴其實就是電腦幫我們把「還沒做完的事」疊起來，那我們自己疊就好了。

#### 用陣列自己做堆疊

我自己用一個陣列 st 當成堆疊，再用 top 記錄現在疊到第幾個位置，最後放上去的最先拿下來。

#### 堆疊只存 m

堆疊裡面只放還沒處理的 m。   n 只有一個數字，所以一個變數一直更新就好。

#### 每次取出 m 的三種情況

每次從堆疊拿出最上面的 m，然後看三種情況：

- **m 是 0**：n 加 1，這一步就做完了。
- **n 是 0**：把 m-1 放進堆疊，然後把 n 改成 1。
- **其他情況**：先放 m-1，再放 m，然後 n 減 1。這樣下一圈會先處理 m，等它做完才輪到 m-1。

#### 堆疊空了就是答案

堆疊空了就代表全部做完，這時候的 n 就是答案。

#### 每組資料前要重設 top

每次算新的一組資料之前，要先把 top 設成 0，不然上一組的東西會影響這一組。

## 程式實作

### 遞迴程式

```cpp
#include <iostream>

using namespace std;

int a(int m, int n) {
	if (m == 0) return n + 1;
	else if (m > 0 && n == 0) return a(m - 1, 1);
	else if (m > 0 && n > 0) return a(m - 1, a(m, n - 1));
}

int main()
{
	int m, n;
	while (cin >> m >> n) {
		cout << a(m, n) << endl;
	}
	return 0;
}
```

### 非遞迴程式

```cpp
#include <iostream>
using namespace std;

int st[10000000];
int top = 0;

void push(int x) {
	st[top++] = x;
}

int pop() {
	return st[--top];
}

int ackermann(int m, int n) {
	top = 0;
	push(m);
	while (top > 0) {
		m = pop();
		if (m == 0) {
			n++;
		}
		else if (n == 0) {
			push(m - 1);
			n = 1;
		}
		else {
			push(m - 1);
			push(m);
			n--;
		}
	}
	return n;
}

int main()
{
	int m, n;
	while (cin >> m >> n) {
		cout << ackermann(m, n) << endl;
	}
	return 0;
}
```

### 非遞迴執行過程，以 A(1,1) 為例

| 步驟 | 拿出來的 m | 這時的 n | 做了什麼 | 堆疊裡剩下（左邊是底部） | 新的 n |
|------|-----------|---------|----------|------------------------|--------|
| 開始 | 無 | 1 | 放入 1 | 1 | 1 |
| 1 | 1 | 1 | 放入 0 和 1，n 減 1 | 0 1 | 0 |
| 2 | 1 | 0 | 放入 0，n 變 1 | 0 0 | 1 |
| 3 | 0 | 1 | n 加 1 | 0 | 2 |
| 4 | 0 | 2 | n 加 1 | 空的 | 3 |

## 效能分析

### 遞迴式：
1. 空間複雜度：m=0、1、2 時分別約為 O(1)、O(n)、O(n)；m=3 時約 O(2ⁿ)；m≥4 後會快速成長，容易造成 Stack Overflow[cite: 1]。
2. 時間複雜度：m=0 時為 O(1)；m=1 時約 O(n)；m=2 之後快速增加；m=3 約為 O(2ⁿ)，m≥4 後複雜度會遠超過指數等級[cite: 1]。

### 非遞迴式：
1. 空間複雜度：m=3 時約 O(n)；m=4 時約 O(2ⁿ)；m≥5 後會快速成長，需要非常大的 Stack 空間[cite: 1]。
2. 時間複雜度：m=3 約為 O(2ⁿ)；m=4 之後會快速超過指數等級。實際計算 Ackermann(4,2) 就需要非常多次操作[cite: 1]。

## 申論及開發報告

### 這題用到的資料結構是堆疊
本題核心是具備「後進先出 (LIFO)」特性的堆疊 (Stack)。遞迴運作時，電腦本質上就是在利用系統的 Call Stack，將每次呼叫的 `m`、`n` 與返回位址存成 stack frame。

### 為什麼非遞迴也用堆疊
非遞迴版本無法只用一般迴圈，必須透過堆疊來記錄「待處理事項」以維持正確順序。透過觀察發現，我們自己建的堆疊只需儲存 `m`，`n` 則用單一變數持續更新即可，這比系統儲存完整的 stack frame 節省非常多空間。

### 用陣列做堆疊
選擇陣列做堆疊，是因為其記憶體連續、操作快且程式碼精簡：
- **push**：`st[top++] = x`
- **pop**：`st[--top]`
- **判斷是否為空**：只需檢查 `top == 0

# 題目二：冪集（Power Set）

## 解題說明

這題要輸入一個集合，然後把它所有的子集合都印出來，這些子集合合起來就叫冪集。

如果集合有 n 個元素，就會有 2 的 n 次方個子集合，空集合和集合本身也都算。

例如集合 {A, B, C}，它的冪集是：

```text
{}, {A}, {B}, {C}, {A,B}, {A,C}, {B,C}, {A,B,C}
```

輸入的格式是第一行先給元素的個數 n，接下來給 n 個元素，每個元素都當成字串。

## 解題策略

我把每個元素都想成要做一個選擇，要放進子集合，或是不放。全部的元素都選完，就是一個子集合。

#### 寫一個遞迴函式 pow

我寫了一個遞迴函式 pow，它有五個參數：

- **A**：原本的集合。
- **s**：現在正在組合的子集合。
- **i**：現在輪到第幾個元素。
- **n**：集合有幾個元素。
- **t**：s 裡面現在放了幾個元素。

#### 全部選完就印出來

如果 i 等於 n，代表所有元素都選完了，這時候 s 的前 t 個就是一個子集合，直接印出來。

#### 先處理不放的情況

如果還沒選完，就先處理不放 A[i] 的情況，直接去看下一個元素。

#### 再處理要放的情況

接著處理要放的情況，把 A[i] 放到 s[t]，t 加 1，再去看下一個元素。

#### s 只用一個陣列

s 只有一個陣列，沒有每次都開新的。因為我們只看前 t 個，後面的不管它，所以不用特別把東西清掉。

整個過程就像畫一棵樹，每個元素分成選和不選兩條路，走到最下面就是一個子集合。

## 程式實作

```cpp
#include<iostream>
#include <string>
using namespace std;

void pow(string A[], string s[], int i, int n, int t) {    // A[]:集合 s[]:子集 i:目前處理到A[i] n:集合大小 t:子集大小
	if (i == n) 
	{
		cout << "{";
		for (int j = 0; j < t; j++) 
		{
			cout << s[j];
			if (j != t - 1) cout << ",";
		}
		cout << "}" << endl;
		return;
	}
	pow(A, s, i + 1, n, t);        
	s[t] = A[i];                  
	pow(A, s, i + 1, n, t + 1);    
}

int main()
{
	int n;
	cin >> n;
	string* A = new string[n];
	string* s = new string[n];
	for (int i = 0; i < n; i++)
	{
		cin >> A[i];
	}
	cout << "冪集為:" << endl;
	pow(A, s, 0, n, 0);

	delete[] A;
	delete[] s;
	return 0;
}
```

## 程式說明

### 陣列 s 和變數 t

s 的大小是 n，不過只有前 t 格是有用的。

- **不選元素**：t 不變，後面的格子就當作沒有東西。
- **選元素**：把元素放到 s[t]，t 加 1。

所以每一種情況都用同一個 s，不用為每個子集合都開一個新的陣列。

## 效能分析

設集合有 n 個元素。

### 時間

- 一共有 2ⁿ 個子集合，每個最多印 n 個元素，總時間 **O(n × 2ⁿ)**。

### 空間

- Call stack 最深 n + 1 層，陣列 A 和 s 各 n 格。
- 子集合是邊產生邊印，不會全部存起來，所以總空間只有 **O(n)**。

## 結論

#### 能印出所有子集合

程式可以把所有子集合都印出來，數量也和 2 的 n 次方一樣。

#### 選或不選很適合遞迴

每個元素只有選和不選兩種可能，用遞迴很適合。

#### s 搭配 t 不用清除

陣列 s 配合 t 來決定哪些格子有用，不用另外把東西清掉，程式比較簡單。

#### 時間與空間

時間是 O(n × 2^n)，空間是 O(n)。

#### 特殊情況也正確

n 等於 0 或 1 這種比較特別的情況也都能算對。

## 申論及開發報告

### 這題用到的資料結構

#### 一、陣列和動態配置

集合的元素放在陣列 A 裡面，因為要等使用者輸入 n 才知道要放幾個，所以我用 new 在執行的時候才決定大小，用完再用 delete[] 。

#### 二、s 和 t 其實是一個堆疊

仔細看 s 和 t 的用法，會發現它就是一個用陣列做的堆疊：

- **push**：選元素的時候，s[t] = A[i]，t 加 1。
- **pop**：回到上一層的時候，t 會自動變回原本的值，不用另外寫。

這是因為每一層遞迴的 t 都是各自一份，回到上一層，上一層的 t 還是原來的數字，後面多放的元素就不算了。

#### 三、Call Stack

遞迴的時候，系統同時最多只會有 n + 1 層函式在等，所以空間很省。如果把全部 2 的 n 次方個子集合都存起來，記憶體會大很多。

### 為什麼用遞迴

冪集有一個很好用的特性，n 個元素的冪集，可以拆成兩半：不含第一個元素的子集合，和含第一個元素的子集合，這兩半都是 n-1 個元素的冪集問題。
